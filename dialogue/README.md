# 대본 쓰는 법

대사는 이 폴더의 `.txt` 파일에 쓴다. Godot 에디터에서 더블클릭하면 바로 열어서 고칠 수 있다.

## 기본

```
# 샵(#)으로 시작하는 줄은 메모. 게임에 안 나옴

== 블록이름
나레이션은 이름 없이 그냥 쓴다.
A: 이름 뒤에 콜론(:)을 붙이면 그 캐릭터의 대사.
B(smile): 괄호 안에 표정을 쓰면 표정 얼굴이 나온다.
A: (괄호로 감싸면 속마음 느낌)
end
```

- **블록**: `== 이름`으로 시작하는 덩어리. 게임에서는 "어떤 파일의 어떤 블록을 재생해라"라고 부른다.
- 블록 끝까지 가거나 `end`를 만나면 대화가 끝난다.
- **표정**: `B(smile)`이라고 쓰면 `art/portraits/B_smile.png`를 찾고, 없으면 기본 얼굴 `B.png`를 쓴다.
  표정 이름은 영어로 쓰는 걸 추천 (맥/윈도우에서 한글 파일 이름이 깨지는 경우가 있어서).
- 대사 안에서 `[color=#ff0000]빨간 글씨[/color]`, `[b]굵게[/b]`, `[shake]떨림[/shake]` 같은 효과를 쓸 수 있다.

## 선택지

```
* 열어 본다 -> box_open
* 그냥 둔다 -> box_leave
```

`*`로 시작하는 줄을 연달아 쓰면 선택지가 된다. `->` 뒤에는 고르면 이동할 블록 이름.

## 다른 블록으로 이동

```
-> box_after
```

## 변수 (호감도, 이벤트 진행 여부)

```
set affection_b + 1      # 1 더하기
set affection_c - 1      # 1 빼기
set met_c = 1            # 값 정하기
if affection_b >= 2 -> b_event     # 조건이 맞으면 그 블록으로 이동
```

- 처음 쓰는 변수는 0부터 시작한다.
- 비교: `>=`, `<=`, `>`, `<`, `==`, `!=`
- 변수는 게임 전체에서 공유된다 (다른 대본 파일에서도 같은 값).

## 게임에 연결하기

- **물건 조사**: 맵에 `scenes/props/interactable.tscn`을 놓고, 인스펙터에서 `Dialogue File`과 `Block`을 정한다.
- **방에 들어오자마자 대화**: 방(Room)의 `Intro Dialogue`, `Intro Block`을 정한다.
- **코드에서**: `Dialogue.start("res://dialogue/파일.txt", "블록이름")`
