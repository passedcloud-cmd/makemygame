== box
낡은 나무 상자다. 뚜껑이 살짝 열려 있다.
B: 함부로 만지지 마. 뭐가 튀어나올지 모르잖아.
C: 그래도 단서가 있을지도 몰라.
* 열어 본다 -> box_open
* 그냥 둔다 -> box_leave

== box_open
set affection_c + 1
A: ...열어 볼게.
안에는 아무것도 없었다. 바닥에 크레파스 자국만 남아 있다.
C(smile): 그래도 확인해 봐서 다행이다. 그치?
-> box_after

== box_leave
set affection_b + 1
A: ...역시 그냥 두자.
B: 현명하네. 생각보다는.
A: 그거 칭찬 맞지?
-> box_after

== box_after
if affection_b >= 2 -> box_b_close
end

== box_b_close
B: ...너, 은근히 내 말 잘 듣는다?
end
